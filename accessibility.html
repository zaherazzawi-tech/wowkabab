Accessibility.

Everyone should be able to find us, read our menu, and order a kabab — whatever device or assistive technology they use. That's the standard we build this website to.

Our target

This site aims to conform to the Web Content Accessibility Guidelines (WCAG) 2.2, Level AA.

What we do

  • Semantic HTML with real buttons, links, and headings that assistive technology can read
  • Full keyboard operability with a visible focus indicator on every interactive element
  • Text contrast that meets or exceeds the 4.5:1 minimum
  • Text descriptions for meaningful images
  • Moving content that pauses on hover, via the "Pause motion" control, and automatically for visitors with a reduced-motion preference
  • Layouts that work at 200%–400% zoom and on small screens
  • Automated and manual accessibility testing before updates go live, with dated records kept

Known limitations

The homepage's main artwork contains stylized text as part of the illustration. Its content is provided in the page's heading and image description, and every action shown in the artwork is available as a real button or link on the page.

Tell us if something isn't working

If any part of this site is hard to use with your assistive technology, we want to know and we'll fix it.
